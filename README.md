# Agro Connect — Kisan se Bazaar tak

Premium Next.js frontend for connecting farmers to markets.

## Stack

- Next.js (App Router)
- Tailwind CSS
- styled-components

## Flow

1. Login first: `/` — dummy JSON auth (`src/data/users.json`)
2. Farmer desk: `/home`
3. Sell activity on the landing page:
   - Select crop + quantity
   - Token payment ₹500
   - Book date/time slot
   - Confirmation
   - Track crop to mandi

## Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Choose **EN** or **हिं** on login. The same language stays on the farmer desk.
